# v0.1.60 发布说明

本版本修复第三方 API 模型同步与直连配置不一致的问题。

## 修复内容

- Provider 卡片增加“同步模型”，始终使用该卡片对应的 Base URL 和 API Key 获取模型。
- 模型列表保留 `/v1/models` 返回的原始模型 ID，不再根据渠道名称猜测模型。
- 用户可在弹窗中选择需要的模型，并为每个模型单独启用 1M 上下文。
- 直连模式不再自动生成 Opus、Sonnet、Haiku 角色映射。
- OpenAI / Codex 类型选择直连时，同样将用户选择的上游模型 ID 原样写入 Claude Desktop。
- 模型接口失败时直接显示错误，不再回退到内置的预设 Claude 模型列表。
- Gateway 模式继续保留显式模型映射能力，但不会影响直连配置。

## 验证

- 前端 JavaScript 语法检查通过。
- Rust 工作区测试通过。
- Tauri 桌面端测试通过。
- 新增回归测试，确认直连配置中的 `inferenceModels` 保留上游原始模型 ID。
