# v0.1.56

## macOS 安装修复

- Claude++ 的个人 macOS 安装流程只使用 Anthropic 官方 Universal DMG。
- 不再默认打开企业部署用 PKG，避免出现标题为空的 macOS Installer 向导。
- DMG 下载失败时打开 Claude 官方下载页，不再静默切换到 PKG。
- 安装和修复提示明确要求将 `Claude.app` 拖入 Applications；升级或修复时替换旧版本。
- 保留官方下载域名检查和 DMG 完整性校验。

## 按系统显示就绪状态

- Windows 显示管理员权限、固件虚拟化、Hypervisor、MSIX/Appx、VMP 和重启状态。
- macOS 显示 macOS 版本、Intel/Apple Silicon 架构、Claude 安装位置、Anthropic 应用签名和 Gatekeeper 状态。
- macOS 不再显示 VMP、Appx、Hyper-V 或“以管理员重新打开”等 Windows 专属项目。
- 体检报告在 macOS 上改用系统版本、架构和应用签名判断，不再把 modern installer/VMP 当成 macOS 必需项。
