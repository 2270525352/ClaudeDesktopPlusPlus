# v0.1.48 发布说明

本版本修复 Claude Desktop 最新版本始终显示 `-`、状态停留在“未检查”的问题。

## 问题原因

Anthropic 官方下载接口返回 HTTP 307，并在 `Location` 响应头中提供带版本号的真实安装包地址。关闭自动跳转后，旧代码错误地把 307 当作普通成功响应并读取原始 `/latest/redirect` URL，导致无法提取版本号。

## 修复内容

- 对所有 3xx 响应显式读取 `Location`。
- Windows MSIX 与 macOS Universal PKG 共用正确的重定向处理。
- 应用启动并读取本地状态后，后台自动执行版本检查。
- 进入“系统就绪”页面仍可手动刷新或再次检查。
- 版本检查失败时显示“检查失败”，并保留具体错误信息，不再退回无信息的“未检查”。
- 新增 `--claude-plus-check-updates` 无界面诊断命令，方便安装包发布前验证真实更新响应。
