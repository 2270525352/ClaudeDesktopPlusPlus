# v0.1.51 发布说明

## 直连优先

- 新配置默认使用直连 3P Provider，不再默认启用或启动本地 Gateway。
- 前端在配置缺省时也统一显示直连，避免界面与后端策略不一致。
- OpenAI、Codex、Kimi、DeepSeek、Qwen、GLM 等快捷配置默认按直连保存。
- 只有上游未提供 Claude 兼容协议或模型映射时，用户才需要手动切换 Gateway。
- OpenAI/Codex 直连不再被总览标记为异常；兼容性提醒仍会说明上游映射要求。
- 已经由用户明确启用的 Gateway 配置会继续保留，不会被强制覆盖。

## 验证

- Windows 实机启动后确认 `127.0.0.1:49331` 未监听。
- 控制台“直连”选中，“Gateway”未选中。
- Claude Desktop 启动结果为“配置启动 + 直连 / 直连 3P Provider”。
- Rust 桌面端测试 9 项通过，1 项网络测试按设计忽略；前端 JavaScript 语法检查通过。
