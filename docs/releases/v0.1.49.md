# v0.1.49 发布说明

## 修复

- 修复 Windows 隐藏 PowerShell 在解析 Claude Desktop 官方重定向时异常退出的问题。
- Claude Desktop MSIX 改由 Rust 解析地址并流式下载，不再依赖 `Invoke-WebRequest -MaximumRedirection 0`。
- 非管理员运行时，安装阶段会单独请求 Windows 管理员授权。
- 安装失败时展示 Appx 部署的 HRESULT、ActivityId 和 PowerShell 详细错误。

## 新增

- Claude Desktop 与 Claude++ 版本卡片增加独立实时进度条。
- 显示检查、解析地址、下载、管理员授权、安装和打开安装器等阶段。
- 下载阶段显示百分比、已下载大小和安装包总大小。
- macOS Claude Desktop PKG 与 Claude++ DMG/EXE 下载共用同一套进度回传。

## 验证

- Windows 实测 Claude Desktop Appx 从 `1.15962.1.0` 升级到 `1.24012.9.0`。
- 实测下载进度、管理员授权、安装完成和最新版状态均能同步到桌面 UI。
