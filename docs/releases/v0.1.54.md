# v0.1.54

## macOS Claude Desktop 修复

- 修复旧版“一键汉化”直接写入 `Claude.app/Contents/Resources`，导致 Apple 代码签名失效并提示“Claude 已损坏”的问题。
- macOS 汉化改为运行时脚本与语言配置，不再修改已签名的 Claude 应用包。
- 启动 Claude Desktop 前校验 Anthropic 签名与 Gatekeeper 状态。
- 自动识别并精确回滚 Claude++ 旧版写入的汉化文件和语言白名单；不会删除内容不一致的用户文件。
- 无法安全回滚时，“一键安装 Claude Desktop”会下载并打开新的官方 PKG 或 DMG，用于覆盖修复。
- 下载后校验官方域名、PKG 签名或 DMG 完整性，拒绝未知来源的安装文件。
- Claude 被 Gatekeeper 拦截时不再只显示误导性的 CDP 超时；新版会报告应用完整性问题，并在仅实时脚本不可用时自动退回配置启动。

## 验证

- Windows Rust 单元测试通过，包括旧 macOS 汉化补丁精确清理测试。
- JavaScript 语法检查通过。
- Windows x64、macOS Intel x64 和 macOS Apple Silicon arm64 安装包由 GitHub Actions 构建。
