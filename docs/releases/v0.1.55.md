# v0.1.55

## 启动版本检查

- Claude++ 启动时优先发起自身版本检查，同时继续加载主界面，避免网络较慢时阻塞应用。
- 检测到新版后弹出升级提示，明确展示当前版本和最新版本。
- 用户可选择“立即升级”或“稍后”；立即升级会进入系统就绪页并显示下载与安装进度。
- 启动检查只请求 Claude++ 的 GitHub Release，不再连带扫描 Claude Desktop 版本。
- 用户确认升级后只复核 Claude++ 版本，避免重复执行较慢的 Claude Desktop 更新检查。
- 更新检查失败不会阻止 Claude++ 启动，并会在运行日志中记录原因。
