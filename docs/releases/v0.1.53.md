# v0.1.53 发布说明

## macOS Claude Desktop 安装修复

- 修复一键安装或升级 Claude Desktop 时，官方 Universal PKG 跳转地址返回 HTTP 403 后直接终止的问题。
- 官方下载请求增加浏览器兼容请求头，降低 Cloudflare 对应用内 HTTP 客户端的误拦截。
- 应用内解析失败时，自动使用 macOS 自带的 `/usr/bin/curl` 重新解析官方跳转。
- PKG 解析或下载失败时，自动尝试 Anthropic 官方 Universal DMG。
- macOS 大文件下载统一使用系统 curl，支持跳转、超时、失败重试和实时已下载字节进度。
- PKG 与 DMG 都被当前网络拒绝时，自动打开 Anthropic 官方下载页面，并在运行日志保留每级失败原因。
- 下载完成后根据真实文件类型打开 PKG 或 DMG，不再固定假设安装文件一定是 PKG。

## 官方来源

Anthropic 官方 macOS 部署文档确认同时提供 PKG 与 DMG，Universal 构建兼容 Intel 和 Apple Silicon：

<https://support.claude.com/en/articles/12611117-deploy-claude-desktop-for-macos>

## 验证

- 官方 Universal PKG 与 Universal DMG 跳转地址均已解析到版本化下载地址。
- Rust 测试 13 项通过，1 项外部网络测试按设计忽略。
- Windows 回归编译通过；macOS ARM64 和 Intel x64 由 GitHub Actions 原生 Runner 构建并验证。
