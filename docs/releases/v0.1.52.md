# v0.1.52 发布说明

## 安装包

- Windows 10/11 x64：`ClaudePlus-Windows-x64-Setup.exe`
- Apple Silicon（M1/M2/M3/M4/M5）：`ClaudePlus-macOS-arm64.dmg`
- Intel Mac：`ClaudePlus-macOS-x64.dmg`

## 第三方模型选择

- 第三方 API 获取模型成功后自动打开模型选择窗口。
- 支持搜索、全选、清空，只把勾选的模型写入 Claude Desktop 配置。
- 每个模型可以独立启用 1M 上下文标记；只有上游模型确实支持时才应开启。
- OpenAI / Codex 兼容 Provider 会根据所选模型生成 Claude 路由映射，最多支持九条路由。
- 重新编辑 Provider 时会保留模型目录、勾选状态和 1M 设置。

## cc-switch 同步修复

- 使用 SQLite 只读模式打开 `cc-switch.db`。
- Claude++ 启动、刷新和手动同步均不会改写 `cc-switch.db` 或 `settings.json`。
- 同步更新 URL、Key 和名称时，保留 Claude++ 中配置的协议、模型映射、模型选择和启用状态。
- 已经选择的 Claude++ 当前渠道不会在每次启动时被 cc-switch 当前渠道强制覆盖。
- cc-switch 中已经删除的渠道仍会从 Claude++ 同步列表中移除。

## 历史修复

- Windows 历史对话页面增加“重置状态”。
- 重置会清除扫描缓存、修复结果和界面残留，随后可以重新扫描并选择新的来源。
- 重置不会删除历史文件或已有备份。

## Windows 启动体验

- Debug 与 Release 桌面构建统一使用 Windows GUI 子系统。
- 启动 Claude++ 时不再出现终端黑框。
- Gateway、PowerShell 和其他辅助子进程继续使用隐藏窗口方式运行。

## 验证

- JavaScript 语法检查通过。
- Rust 测试 12 项通过，1 项外部网络测试按设计忽略。
- Windows 实机桌面进程启动正常，窗口可响应。
- Claude++ 启动同步前后，`cc-switch.db` 和 `settings.json` 的 SHA-256 与修改时间均保持不变。
