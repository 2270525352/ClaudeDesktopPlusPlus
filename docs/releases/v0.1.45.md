# v0.1.45 发布说明

本版本集中处理生产安装包、Claude Desktop 启动兼容性和内置技能包可逆管理，并恢复 macOS Intel 安装包。

## 主要修复

- 生产版界面改为随应用内嵌，不再依赖 `127.0.0.1:5177` 本地开发服务。
- 修复新版 Claude Desktop 安装路径探测与启动后进程确认，兼容 Squirrel、MSIX 和 WindowsApps 安装。
- 注入启动在 CDP 调试端口未及时就绪时增加兼容探测与清晰错误，不再把激活进程误报为已成功启动。
- 卸载 Claude++ 时恢复由工具写入的 Claude Desktop 路由配置，避免残留第三方路由导致原版 Claude 无输出。
- 内置 broken 技能包支持安装、更新、卸载和重新安装。
- 卸载技能包时会恢复安装前同名技能；安装失败会自动回滚，避免破坏用户已有技能。

## 安装包

- Windows x64：NSIS 安装程序。
- macOS Apple Silicon：ARM64 DMG。
- macOS Intel：x64 DMG。

Windows 安装包由本机完成构建验证；三个平台的正式产物由 GitHub Actions 在 `v0.1.45` 标签发布时生成。
