# v0.1.59 发布说明

本版本修复 Claude++ 主窗口的最小化、关闭与系统托盘行为。

## 修复内容

- 点击最小化后，窗口正常保留在任务栏，不再被自动隐藏。
- 点击窗口关闭按钮或使用 `Alt+F4` 时，主窗口隐藏到系统托盘，Claude++ 后台进程继续运行。
- 单击托盘图标或选择“显示 Claude++”可以重新打开主窗口。
- 只有选择托盘菜单中的“退出 Claude++”才会完全结束程序。

## 验证

- Windows 编译检查通过。
- Rust 测试通过：19 项通过，1 项按设计忽略。
- 实际窗口测试确认关闭后主窗口隐藏且进程继续运行。
- 实际窗口测试确认最小化后窗口保持可见的最小化状态。
