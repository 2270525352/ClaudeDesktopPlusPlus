# v0.1.58

## 修复官方插件市场同步

- “同步官方目录”不再把 Claude CLI 作为唯一同步通道。
- macOS GUI 环境会额外探测 `~/.local/bin/claude`、`~/.claude/bin/claude`、Homebrew 和 MacPorts 等常见安装位置。
- 支持通过 `CLAUDE_CLI_PATH` 指定 Claude CLI 的完整路径。
- 未安装 Claude CLI 时，Claude++ 会使用 Git 直接 clone 或更新 Anthropic 官方插件仓库。
- Git 同步完成后自动写入 Claude 官方格式的 `~/.claude/plugins/known_marketplaces.json`，以后安装 CLI 后可以继续使用同一目录。
- 插件目录同步与插件安装职责分离：同步只需要 Git，安装插件仍需要 Claude CLI。

## 安全与诊断

- 已有市场目录包含本地改动时不会覆盖。
- 已有目录不是 Git 仓库时不会删除或替换其中内容。
- Git 命令禁用交互式凭据提示并设置超时，避免界面长期卡住。
- 新增 `--claude-plus-sync-official-plugins` 无界面诊断命令。
- 已在隔离的无 CLI 环境中实际同步官方仓库并解析出 276 个插件。
