# v0.1.50 发布说明

## 启动流畅度

- Claude Desktop 的启动、进程确认和配置验证改为后台任务，控制台界面不再被同步命令占住。
- 点击启动后立即显示“正在启动”，并临时锁定其他启动入口，防止重复点击造成进程争抢。
- Windows Claude Desktop `1.24012.9` 及后续版本直接使用已生效的 Claude-3p 配置启动，不再先等待一次已知会失败的 CDP 参数启动。
- 直连模式移除不必要的固定验证等待；Gateway 模式仍保留请求观察时间。
- Windows 只对 Claude 根进程执行一次完整进程树清理，既避免重复遍历，也会关闭其插件子进程。
- macOS 会等待旧 Claude 实例完全退出，必要时升级为强制结束，避免单实例锁竞态。

## 实机验证

- Windows Claude Desktop `1.24012.9` 使用直连 3P Provider 启动成功。
- 从 Claude++ 配置写入到 Claude 主进程出现由约 4.4 秒缩短到约 0.9 秒。
- 主进程未携带 `remote-debugging` 参数，Claude 子进程继续使用 `Claude-3p` 用户数据目录。
- Rust 桌面端测试 8 项通过，1 项网络测试按设计忽略；前端 JavaScript 语法检查通过。
