# v0.1.47 发布说明

本版本简化 Release 安装包，并补全 Windows 与 macOS 的 Claude Desktop 版本识别和更新流程。

## 下载说明

- Windows 10/11 x64：`ClaudePlus-Windows-x64-Setup.exe`
- Apple Silicon（M1/M2/M3/M4/M5）：`ClaudePlus-macOS-arm64.dmg`
- Intel Mac：`ClaudePlus-macOS-x64.dmg`

Release 不再额外上传 `.app.tar.gz`，避免用户把开发产物误认为安装包。

## Claude Desktop 更新

- 打开“系统就绪”页面后，并行检查系统状态、Claude Desktop 和 Claude++ 版本。
- Windows 优先读取 MSIX/Appx 版本，并兼容旧 Squirrel `app-x.y.z` 安装目录。
- macOS 从 Claude.app 的 `Info.plist` 读取当前版本。
- Windows 使用 Anthropic 官方 x64 MSIX 更新地址。
- macOS 使用 Anthropic 官方 Universal PKG，同时适配 Intel 与 Apple Silicon。
- 未安装时按钮显示“安装 Claude Desktop”；发现新版本时显示“升级 Claude Desktop”。
- 已是最新版本时禁用重复更新；版本无法比较时仍允许用户下载安装程序进行修复。
