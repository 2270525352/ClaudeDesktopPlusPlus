# v0.1.57

## 修复 macOS 假启动

- Claude++ 不再直接执行 `Claude.app/Contents/MacOS/Claude`，改为通过 macOS LaunchServices 启动完整应用包。
- 启动命令使用独立实例并透传 CDP 参数，确保 Claude 窗口由系统正常激活。
- 进程确认不再接受短暂存活的启动 PID，也不再仅按 `Claude` 进程名判断。
- Claude++ 会从系统进程列表匹配当前所选 `Claude.app` 的真实主进程，并要求进程稳定存活后才报告启动成功。
- CDP 等待结束后会再次检查 Claude 主进程；如果应用已经退出，操作直接返回失败，不再显示“已启动”。
- 如果 Claude 因 CDP 参数延迟退出，Claude++ 会自动清理失败实例并用配置模式重新启动，保证应用能够真正打开，同时明确提示实时脚本未生效。

## 修复 macOS 汉化

- 汉化 locale 同时写入官方 Claude 和 Claude-3p 的用户配置目录。
- 通过应用偏好设置写入 `AppleLanguages` 与 `AppleLocale`，不修改已签名的 `Claude.app`。
- 运行时汉化脚本仍通过 Claude++ 启动时的 CDP 通道加载。
- 汉化状态现在区分“已配置，待启动生效”和“已启用”；只有实时脚本注入成功后才显示为已启用。
- 汉化配置提示不再把 locale 写入成功误报为界面汉化已经生效。

## 启动参数与回归测试

- CDP 仅监听 `127.0.0.1`，并使用对应本地 Origin。
- 增加 macOS LaunchServices 命令测试。
- 增加所选 `Claude.app` 主进程路径匹配测试，避免命中其他安装、副进程或 `open` 启动辅助进程。
